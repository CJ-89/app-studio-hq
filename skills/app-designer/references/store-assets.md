# Play Store assets

Check current specs in Play Console at upload time; these are the long-standing requirements.

| Asset | Spec |
|---|---|
| App icon (store) | 512 × 512 PNG (32-bit, with alpha), max 1 MB |
| Adaptive launcher icon | Foreground + background layers, 108 × 108 dp with the key art inside the central 66 dp safe zone; add a monochrome layer for themed icons |
| Feature graphic | 1024 × 500 JPEG or 24-bit PNG (no alpha) |
| Phone screenshots | At least 2 (aim for 4–8), PNG/JPEG, 16:9 or 9:16, each side 320–3840 px |
| Tablet screenshots | Recommended if the app supports tablets |
| Promo video | Optional YouTube link |

## Screenshot storytelling (most important ASO visual)
1. Screenshot 1 = the core value in one bold headline + the hero screen.
2. Screenshots 2–4 = one benefit each.
3. Last = social proof or the premium feature.
- Headline ≤ 6 words, large type, high contrast. Use real app UI, not fake features (policy: screenshots must reflect the app).
- Localize headlines for each listing language.

## Icon rules
- One simple shape, readable at 48 px, no text, no Play badges or misleading marks, distinct from top competitors.
