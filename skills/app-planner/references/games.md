# Game planning add-on (Unity games)

## Extra interview questions (one at a time)
1. Genre and reference games ("like X but Y")
2. Session length target (30 s hyper-casual / 2–5 min casual / 10+ min mid-core)
3. Core loop in one line (action → reward → progression)
4. Content: endless/procedural vs hand-made levels (hand-made = more work per hour of play)
5. Art style you can realistically produce (asset store, AI-assisted, pixel art, simple shapes)

## Extra research
- Play Store top free + top grossing in the genre; read 1–3★ reviews for "too many ads", "pay to win", "boring after level N".
- Check if the genre is saturated by big studios (if top 10 are all large publishers, pick a sub-niche).

## Game scorecard checks (add to the main scorecard notes)
| Check | Pass if |
|---|---|
| Hook in 10 seconds | The fun is obvious without a tutorial |
| Replayability | Players want "one more round" (variation, mastery, progression) |
| Scope fits solo dev | MVP doable in ≤ 8–10 weeks with available art |
| Ad fit | Natural rewarded moments (revive, double reward, hint, skip) and breaks for interstitials |
| Kid appeal risk | If it looks childlike, Families policy may apply — adjust art/theme or accept the rules |

## MVP for a game
- 1 core mechanic, 1 game mode, 10–20 levels or an endless mode, basic progression (stars/score/unlocks), settings (sound, music, vibration), one rewarded placement, one interstitial placement.
- Won't in v1: multiplayer, live events, complex economies, cloud save (unless core).

## Metrics (casual games starter targets)
D1 35%+, D7 10%+, average session 3+ min, rewarded views per DAU 1+. Treat as rough starting points.
